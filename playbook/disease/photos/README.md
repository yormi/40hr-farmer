# Disease / scouting reference photos

Source: Catherine Sylvestre's "Banque de photos 2020" Drive folder,
weeks 24-46. Sorted `crop/issue/`. 550 files, ~1.2 GB.

**Not committed to git** (see `.gitignore` here). Too large for the
repo; the images live locally only. `README.md` + `manifest.csv` are
tracked so the index survives. See `manifest.csv` for the full
crop/issue/count list.

## Notes

- `issue` = the disease/pest/disorder label from the source name,
  cleaned (accents, plant/week/lab codes stripped, lowercased).
- Filenames keep a `sNN-` week tag for provenance. Photos inside the
  original `.docx` samples were extracted from the doc.
- Typo/format twins merged: `milidou`→`mildiou`,
  `alternariasolani`→`alternaria-solani`, `tetranyques`→`tetranyque`,
  and the moisissure/sphinx/alternata spelling variants.
- Distinct Alternaria labels kept separate on purpose (`alternaria`,
  `alternaria-solani`, `alternaria-alternata`, `alternariose`,
  `didymella-alternaria`) — the farm used them as different diagnoses.
- `cucumber/unlabeled-wilt-plant30` — 2 photos from `Semaine 24/30`,
  no disease label; cucumber sudden wilt, likely the same
  Pythium myriotylum documented that week.
- 7 source folders were empty in the download and skipped: a
  Fusarium oxysporum (wk28), and several wk38 folders (Coccinelle,
  Microtechnites, a tobacco aphid, two spotting notes).
