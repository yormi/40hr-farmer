# Science

How the crop works. The shared model the playbook reasons
against, and the words it reasons with.

**Science says what IS true. The playbook says what to DO.**
No steps, no cadences, no "check this weekly" here. If a line
tells you to act, it belongs in a playbook card.


| File | Covers |
|---|---|
| [vigor.md](vigor.md) | The plant's energy pool, the vegetative / generative split, reading it off the head, caliper bands by fruit class. |
| [leaf-energy.md](leaf-energy.md) | One leaf's carbon budget: light interception, age, respiration, construction cost, net importer vs exporter, compensation depth. |


## Layout of a file

- **Model** — the relationships, grouped by sub-mechanism.
  Structural (`A 1—* B`), causal (`radiation → leaf temp`),
  and quantitative (target bands, balance equations).

- **Invariants** — standing truths that aren't already an edge.

- **Boundaries** — what the file does not cover, and where it
  hands off.

- **Vocabulary** — only load-bearing, non-obvious terms.


## Not here

- **Confidence and validation status** → `learnings/`
- **Where a number came from** → `learnings/`
- **Anything you do** → `playbook/`
