# Disease control — the 1-decision engine

One page for every fungal and bacterial disease.

Why → [`science/disease.md`](../../science/disease.md)


## The engine

Runs under every disease, every week.

1. **Keep the zone dry.** Dry the leaf at least once every
   90 min. Never a judgment call.
2. **Prune damaged tissue.**
3. **Scout** → [`weekly-scout.md`](weekly-scout.md). See it? →
   run that disease's block below.
4. **Stop rule, all sprays:** no new spots for 7 straight days →
   stop spraying, keep drying.


## Leaf mold

| | |
|---|---|
| Spread | 1 week |
| Prevent | dry + resistant variety |
| Cull | affected leaves, at weekly scouting |
| Spray | none — climate and variety clear it |


## Bacterial spot

| | |
|---|---|
| Spread | 5 days |
| Prevent | keep the climate dry |
| Cull | leave it |
| Spray | **Badge X2 + Regalia**, underside coverage, **7-day** |

- Pre-harvest 0 days. Re-entry: Badge X2 24 h, Regalia 4 h.


## Sclerotinia

| | |
|---|---|
| Spread | 2 weeks |
| Prevent | dry every 90 min; high pressure → **Contans** to soil pre-season |
| Cull | the **whole plant**, at weekly scouting |
| Spray | none |


## Late blight

| | |
|---|---|
| Spread | **1 day** |
| Prevent | dry every 90 min + resistant variety |
| Cull | the **whole plant**, out of the house, **on sight** |
| Spray | **Badge X2 + Regalia**, underside coverage, **5-day** |

- Pre-harvest 0 days. Re-entry 24 h.
- **Never** snip the spotted leaf and leave the plant.
- Harder to hold in unheated houses. Thrives 55 to 75 °F.


## Early blight

| | |
|---|---|
| Spread | 2 weeks |
| Prevent | dry + mulch against soil splash + tolerant variety |
| Cull | infected leaves, at weekly scouting |
| Spray | **Badge X2 + Regalia**, underside coverage, **7-day** |

- Pre-harvest 0 days. Re-entry: Badge X2 24 h, Cease 4 h.


## Powdery mildew

| | |
|---|---|
| Spread | 1 week |
| Cull | leave it |
| Spray | **Sulfur**, repeat when it returns, not on a clock |

- Sulfur only if the house stays **below 85 °F for 24 h** after
  spraying.
- House runs above 85 °F daily → **MilStop** instead, both-side
  coverage, early AM or evening, every **7 days** while symptoms
  show.
- Never within ~2 weeks of an oil spray.
- Pre-harvest 0 days both. Re-entry: sulfur 24 h, MilStop 1 h.


## Botrytis

| | |
|---|---|
| Spread | 4 days |
| Prevent | dry |
| Cull | fruit; infected + senescing leaves; carve out stem lesions |
| Spray | none — a waste on top of a dry house |

- Prune stubs. They never heal.
- You can carve ~90 % of a stem and the plant lives.
